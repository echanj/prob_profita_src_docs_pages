TrendFollower
=============

.. currentmodule:: Trend_Following_Class

Single-asset trend strategy using MACD signals and Markov-switching regime
metrics. It filters candidates by regime durations and supports crossover or
regime signal modes.

.. autoclass:: TrendFollower
   :no-members:
   :show-inheritance:

The class inherits the common screening, evaluation, and backtesting interface
from :class:`Single_algo_Class.SingleBNBTrader`.
