VectorPairTradeBT
=================

.. currentmodule:: Pairs_factor_algo_class

Pair-trading screener and backtest engine. The instance is configured with a
price DataFrame and screening, signal, and optimization options. Its
``positionsTable`` stores the generated portfolio positions.

.. autoclass:: VectorPairTradeBT
   :no-members:

Attributes
----------

.. py:attribute:: VectorPairTradeBT.df

   Input price matrix indexed by date, with one column per instrument.

.. py:attribute:: VectorPairTradeBT.dailyret

   Fractional returns calculated from ``df``.

.. py:attribute:: VectorPairTradeBT.R

   Preprocessed historical return block used for screening and factor modeling.

.. py:attribute:: VectorPairTradeBT.best_res

   Selected pair strategies and their screening or backtest metrics.

.. py:attribute:: VectorPairTradeBT.positionsTable

   Position matrix for the input dates and instruments.

.. py:attribute:: VectorPairTradeBT.kelly_table

   Pair allocation scaling factors, including covariance- or sign-based
   adjustments when enabled.
