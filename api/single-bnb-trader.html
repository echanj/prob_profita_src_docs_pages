Methods#

SingleBNBTrader.preprocess_data

Clean the lookback return window ending before row t (exclusive) and return its filtered fractional returns.

SingleBNBTrader.preprocess_volumes

Align volume and price lookback windows ending before row t; stores the blocks in self.V and self.P and returns None.

SingleBNBTrader.pca_transform

Fit PCA to the configured return or volume-based matrix and store its loadings and selected symbols; returns None.

SingleBNBTrader.train_model

Fit the multi-output regression from self.X to self.R and return fitted predictions as a DataFrame.

SingleBNBTrader.evaluate_instruments

Build cumulative sums and growth series for observed and modeled returns; stores the results and returns None.

SingleBNBTrader.generate_positions

Populate self.positionsTable at row t from the selected strategies; returns None.

SingleBNBTrader.preprocess_forward_data

Prepare forward returns and factor predictions for the date bounds, using backwindow and signal_length; return both DataFrames.

SingleBNBTrader.generate_Buy_Hold_benchmark

Add buy-and-hold profits for symbols in self.best_res over the requested date bounds at signal_freq; returns None.

SingleBNBTrader.run_gs_and_eval

Optimize and backtest selected symbols; extended_metrics and save_grid_search_res control stored details; returns None.

SingleBNBTrader.run_gs_forward_degradation

Optimize over start_Timestamp/end_Timestamp and store forward results; extended_metrics and save_grid_search_res control details; returns None.

SingleBNBTrader.run_init_forward_degradation

Backtest initial parameters over start_Timestamp/end_Timestamp; extended_metrics controls stored statistics; returns None.

SingleBNBTrader.gen_kelly_factor_table

Create Kelly allocation factors from historical grid-search PnL, optionally using covariance and factor signs; returns None.

SingleBNBTrader.update_zscore_metrics

Recompute stationarity, OU, Hurst, and KPSS metrics for optimized signals using hurst_max_lags and kpss_lags; updates self.best_res.

SingleBNBTrader.get_forward_date_ranges

Build signal and generation date ranges for the requested bounds and lookback window; return both date indexes.

SingleBNBTrader.generate_forward_trading_signals

Generate forward z-score and position series from symbols, parameter sets, price data, and date/frequency settings; return both series lists.

SingleBNBTrader.evaluate_forward_trading_signals

Backtest each generated forward position series and store profit and Sharpe metrics in self.best_res.

SingleBNBTrader.evaluate_position_table

Evaluate portfolio returns from self.positionsTable and optionally return profit, Sharpe, and return statistics when return_metrics is true.

SingleBNBTrader.evaluate_extended_portfolio_metrics

Calculate extended portfolio metrics with the given risk-free rate and annualization factor; return the metrics dictionary.

SingleBNBTrader.plot

Display portfolio returns, positions, equity curve, and benchmark-versus-grid-search profit plots; returns None.

SingleBNBTrader.save

Save instance attributes to savename and, if save_df is true, DataFrames to a companion file; verbose and save_zscores control output and signal storage.

SingleBNBTrader.load

Load saved attributes from loadname and optionally companion DataFrames via load_df; verbose enables progress output.

SingleBNBTrader.get_backtest_date_info

Print input date coverage, approximate periods per day, and the configured evaluation indices; returns None.

SingleBNBTrader.update_best_res_positions_using_subset

Evaluate latest-date signals from df_sub (optionally using factors, plots/HTML, diversification, and extended metrics); return the results table, z-scores, and positions.

SingleBNBTrader.process_model_at_timestep

Rebuild the return window and factor model for row index t; updates model attributes and returns None.

SingleBNBTrader.reoptimize_trading_params

Rerun the configured parameter grid searches for selected strategies and refresh their metrics and Kelly factors.

SingleBNBTrader.get_simulated_profit_metrics

Estimate OU-simulated profit and Sharpe for each row's parameters in pairlist; return the DataFrame with metric columns added.

SingleBNBTrader.get_profits_per_trade

Compute benchmark profit per trade for screened symbols and store it in self.ticker_list_res; returns None.

SingleBNBTrader.use_classifier_get_prob_profita

Train a profitability classifier using self.clf_prob_y and self.clf_profita_offset; stores probabilities and coefficients, returns None.

SingleBNBTrader.plot_prob_profita_model_coefs

Plot all classifier coefficients and the ten largest by absolute value; returns None.

SingleBNBTrader.print_some_trader_settings

Print selected strategy settings and return their dictionary only when return_dict is true.

SingleBNBTrader.diversify_best_res

Select a diversified subset using selected-symbol sectors and return selections, sector data, and correlations; kwargs configure the selection.

SingleBNBTrader.aggregate_deg_stats

Aggregate forward-degradation metrics by parameter ID and symbol; return the enriched results and both summary tables.

SingleBNBTrader.degradation_analysis_and_filter

Analyze in-sample versus forward metrics and optionally filter results; options control metric thresholds, aggregation, outliers, and filtering; returns None.
